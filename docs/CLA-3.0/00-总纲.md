## 一、产品定位

C-LingoAIOS 是面向**非华裔青少年**的中文学习平板系统。它不是一个装在平板上的 App，而是**开机即接管整台设备的学习操作系统外壳**：从开机向导、语言选择、设备激活，到教材、备考、AI 口语、工具箱、应用商店、家长控制，全部在同一套壳层内完成。

### 与竞品的定位差别

| 维度 | 多邻国等通用 App | C-LingoAIOS |
|---|---|---|
| 载体 | 手机 App，与其他 App 争夺注意力 | **独占整台平板**，无外部干扰源 |
| 内容 | 算法生成的碎片练习 | 出版社正式教材 + HSK 官方题库 |
| 目标 | 每日签到留存 | 完成一本书、通过一个 HSK 等级 |
| 变现 | 订阅制 | 硬件销售 + 内容授权 |

定位一句话：**一台开机就只能学中文的平板，用出版教材和 HSK 官方题库把学习者送过等级考试。**

## 二、目标用户

| 维度 | 定义 |
|---|---|
| 年龄 | 12 岁以上，主力 13–19 岁 |
| 地区 | 东南亚（泰国、越南、印尼、马来）+ 欧美 + 中东（阿联酋） |
| 类型 | **非华裔**中文学习者；华裔版本另立项，不在 3.0 |
| 性别 | 女性占比偏高 |
| 起点 | 87% 集中在 HSK1 水平或零基础 |
| 设备关系 | 一人一台，或家庭/学校共用一台 |

### 设计原则（对 3.0 全域生效）

1. **游戏化，不儿童化**。不用 Q 版卡通、不用夸张音效。视觉参照国际化学习 App，面向 teenager 审美。
2. **食指可点**。安卓平板手持或平放使用，最小可点区域按食指指腹尺寸设计，不按鼠标指针设计。
3. **首页一屏不滚动**。核心入口全部一屏内可达。
4. **英文为第一语言**，其余语言逐步扩展。阿拉伯语用迪拜官方阿拉伯语。

## 三、3.0 版本目标

### 目标

1. 把开机到第一次学习之间的路径**收成一条确定流程**（开机向导 5 步 → 学习路径分流 → 落地学习页），消除「打开平板不知道点哪」。
2. 把散落的 68 条路由**收进四个可解释的域**（教材 / 备考 / AI 与工具 / 系统），每条路由要么有真实功能，要么明确标为锁定占位。
3. 把多语言从「界面文案翻译」升级为**真正的多语种壳层**（含 RTL 与字体切换），打开中东与东南亚市场。
4. 把 HSK 备考域**冻结为已交付基线**，本版不动，保护外包交付物与接口契约。

## 六、优先级与 RICE

### RICE 评分口径

`RICE = (Reach × Impact × Confidence) / Effort`

- **Reach**：一个版本周期内接触该功能的设备数占比（0–1）
- **Impact**：3 = 巨大，2 = 高，1 = 中，0.5 = 低，0.25 = 极小
- **Confidence**：1.0 = 有数据支撑，0.8 = 有强逻辑，0.5 = 猜
- **Effort**：人周

> **Reach 与 Effort 全部为推断值 [待确认]**。Reach 无埋点可依，按「该功能在流程中的必经程度」估；Effort 未与开发对过，按代码体量估。**排序可用，绝对分数不可引用。**

### 分级判据（不看分数也能解释）

- **P0**：用户从开机到第一次完成学习的**必经路径**，缺一环流程断掉。

## 九、全局业务流程

### 首次开机主流程

```text
设备首次开机
  ↓
生成匿名 deviceId 写入 localStorage（不采集硬件序列号/指纹/IP）
  ↓
落地 /Home，OnboardingContext 判定 !onboarded → 展开向导覆盖层
  ↓
Step 1 选语言 ─→ Step 2 连 WiFi ─→ Step 3 激活（邮箱 + SN + TOS）
  ↓
Step 4 个人资料（头像 / 昵称 / 生日 / 性别）
  ↓
Step 5 选学习路径（三卡）
  ├─ 「零基础」 → finish('clingo')    → /Home
  ├─ 「已知等级」 → HSK 弹窗（仅 1/2）→ finish('hsk', level) → /hsk-prep-training?level=N
  └─ 「不确定」  → finish('placement') → /hsk-prep-test
  ↓
写入 clingo-onboarded-v1 = '1' 与 clingo-onboard-profile-v1
  ↓
后续启动直接落地 /Home，不再展开向导
```

### 日常学习主流程

```text
/Home 首页
  ├─ 底栏 tab 切换（Home / Library / Camera / Profile + Camera 独立键）
  ├─ 当前书籍卡 → /library/read/:bookId → 单元选择 → /lesson/:id
  │                                                    ↓
  │                              视频（可跳过）→ 练习 → 学习报告 → 回 Hub 显示进度
  │                                                    ↓
  │                                        完成 60% → 解锁 bonus（文化 / 小游戏）
  ├─ HSK 入口 → /hsk-test → /hsk-prep-training（等级锁定：仅 HSK1/2）
  ├─ AI 入口 → /ai-chat → 练习模式 → 对话 → 结束后统一给评分报告
  └─ 工具入口 → 拼音表 / 汉字书写 / 卡片 / 小游戏
```
