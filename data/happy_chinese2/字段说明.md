# JSON 字段说明

数据由 Excel《快乐中文第二册_结构化内容_完整(0715_ml).xlsx》导出。多语言已直接写在对应字段上，不再单独提供 i18n 文件。

取文案时用当前语言，缺省回退中文：`item.title[lang] || item.title.zh`。

多语言文本对象（下文凡写「多语言 xxx」均为此结构）：

```
zh  中文
en  英文
ja  日语
ko  韩语
es  西班牙语
fr  法语
vi  越南语
id  印尼语
th  泰语
```

部分字段没有翻译时，除 `zh` 外可能为空字符串。

---

## catalog.json

存放目录数据。课的 `id`（如 `L20004`）是 `content.json`、`quizzes.json` 的主键。

```
units                         一级目录（单元）列表
	id                        单元资源 ID
	order                     单元序号（1–8）
	title                     多语言单元名称
	lessons                   二级目录（课）列表
		id                    课资源 ID，与 content / quizzes 的课 key 对应
		order                 课序号（1–24）
		title                 多语言课名称
		goals                 学习目标列表
			id                目标资源 ID
			text              多语言学习目标
```

## content.json

存放各课学习内容。顶层 key 为课 ID（与 `catalog.json` 中 `lessons.id` 相同）。

```
L20004                        某一课
	chars                     字卡列表
		id                    字资源 ID
		order                 排序
		text                  多语言汉字
		pinyin                拼音
		hsk                   HSK 等级（如 HSK 1）
		pos                   多语言词性
		strokes               笔画数
		structure             多语言字形结构（如左右结构）
		components            部件组成（汉字数组，如 ["女", "生"]）
	vocab                     词卡列表
		id                    词资源 ID
		order                 排序
		text                  多语言词语
		pinyin                拼音
		hsk                   HSK 等级
		pos                   多语言词性 / 属性
		strokes               笔画数（仅该词同时是字时出现）
		structure             多语言字形结构（同上，可选）
		components            部件组成（同上，可选）
	sentences                 句卡列表
		id                    句子资源 ID
		order                 排序
		text                  多语言句子
		pinyin                拼音
	patterns                  句型卡列表
		id                    句子资源 ID
		order                 排序
		text                  多语言例句
		pinyin                拼音
		formula               句型公式原文（只翻译 {} 中的槽位）
		slots                 公式槽位翻译列表
			id            槽位资源 ID
			text          多语言槽位名称（如「某人」）
	dialogues                 对话卡列表（同一排序合为一段对话）
		order                 对话序号
		scene                 多语言对话场景（部分对话没有此字段）
			id            场景资源 ID
			text          多语言场景说明
		lines                 对白列表
			id            该句资源 ID
			speaker       说话人（A / B 等）
			text          多语言对白
			pinyin        拼音
			pattern       该句结构公式
			slots         结构槽位翻译列表（同句型卡 slots）
	grammar                   语法卡列表
		id                    语法内容资源 ID
		order                 排序
		text                  多语言语法点（如「谁」）
		name                  多语言语法名称（如「疑问代词」）
		pinyin                拼音
		pattern               句型公式原文
		slots                 句型槽位翻译列表
		function              多语言语法功能说明
		examplePattern        例句组成成分公式
		exampleSlots          例句组成成分槽位翻译列表
		examples              例句列表（一般 1–2 条）
			id            例句资源 ID
			text          多语言例句
			formula       带「+」拆分的例句原文
			pinyin        带「+」拆分的拼音
	flashcards                闪卡列表
		id                    词资源 ID
		order                 排序
		text                  多语言词语
		pinyin                拼音
		usage                 多语言用法说明
		example               例句（可选）
			id            例句资源 ID
			text          多语言例句
```

## quizzes.json

存放课堂小测。顶层 key 同样是课 ID；值为该课题目数组（每课 5 题）。

图片相对路径按 `题号/文件名.png` 拼接，对应文件夹 `快乐中文第二册 课堂小测/`。前端自行加静态资源前缀，例如：

`/quiz-images/` + `L010203/L020203A.png`

```
L20004                        某一课的题目列表
	id                        题号（如 L010101）
	type                      原始题型编码（MC_01、MATCH_03 等）
	mode                      choice 选择题 / match 匹配题
	title                     多语言题目名称（表中多为中文，其它语言常为空）
	unit                      表中的单元名称（如「第一单元」）
	lesson                    表中的课次（如「第1课」）
	lessonNo                  课序号数字（1–24）
	lessonId                  课资源 ID，与顶层 key、catalog 课 id 相同

	# mode = choice 时
	stem                      题干
	options                   选项列表
		correct               true 正确答案 / false 干扰项

	# mode = match 时
	stems                     题干列表（题干1–题干5）
		key                   配对编号（1–5，与 options.key 对应）
	options                   选项列表（选项1–选项5）
		key                   配对编号（与 stems.key 相同即为正确匹配）
```

题干、选项共用内容字段：

```
kind                          text 纯文本 / audio 听音频 / image 看图片
text                          多语言文本（从 [音频: 谁]、[图片：高] 中抽出的汉字也在这里）
id                            该条内容的多语言资源 ID（有翻译时才出现）
pinyin                        拼音（有则出现）
image                         前端可访问的图片相对路径，如 L010203/L020203A.png（有图才出现）
audio                         音频 ID（表里极少；图片误填在音频列时会改记到 image）
```

## 文件对应关系


| JSON         | Excel 工作表                                   |
| ------------ | ------------------------------------------- |
| catalog.json | 目录 + 多语言ID                                  |
| content.json | 字卡 / 词卡 / 句卡 / 句型卡 / 对话卡 / 语法卡 / 闪卡 + 多语言ID |
| quizzes.json | 课堂小测 + 多语言ID                                |
